# CyberNight 198X: builds

The game-night hub for the 198X line (CyberCurl, CyberPool, CyberTee and CyberBowl), as built programs only. There is no source here.

**To install:** download `CyberNight198X-Setup.exe` from the [latest release](https://github.com/Joshintexas/CyberNight198X-builds/releases/latest) and run it. Windows may say the publisher is unknown: choose More info, then Run anyway. It installs for your own Windows user, with no admin prompt.

After that, CyberNight updates itself from the releases here, fetching only the games that changed. A friend's invite link opens it straight into their night.
